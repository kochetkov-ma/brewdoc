## Public bundle contract

`results.json` uses schema version 1, record kind `public_full_corpus_bundle`,
`full_run: true`, `expected_count: 31` and `capture_count: 62`. Every selected
input has both passes, including refusals. This bundle contains no partial run.

Each `pass-N/<id>/result.json` is schema version 1,
`portable_capture_derivative`. It records input identity, command template,
versions, timing, status, errors, stream hashes and Markdown identity. Source
paths are repository-relative. Artifact paths in a capture record are relative
to that capture directory. Paths in the root results index are bundle-relative.
Review JSON states its own reference convention; page and line ranges cite the
unchanged source and Markdown bytes.

All 60 Markdown files are unchanged byte copies of observed converter output,
verified against local capture hashes. They are observations, not authored golden
files. No source document or expected-output fixture is duplicated in this bundle.
The original documents retain their [source licenses and attribution](../../../tests/fixtures/SOURCES.md),
including the [upstream Calamine MIT notice](../../LICENSES/calamine-MIT.txt).

Public `receipt.json` files are readable, derived portable copies. For successful
outputs, only `out` changes to capture-relative `artifacts/document.md`. In the two
patent refusals, `out` remains null and the exact original absolute input path
inside `reason` changes to its repository-relative input path. Every other field
and all other reason text remain unchanged. Each record lists these exact
`receipt_transformations`; these JSON files are not raw stdout. Original stdout,
stderr, result records and environment context remain authoritative in the local
immutable capture archive. The public records retain their stream byte counts
and hashes without publishing host paths or local environment dumps.

The local two-pass receipt comparison normalized only `out`. The later public
privacy transformation of the two refusal reasons does not alter that comparison
or the original evidence. Metadata version 2 enriches the frozen version 1
selection without changing input IDs, paths, sizes or hashes. All 31 source
annotation files are included as a snapshot.

Run the existing helper with a 300-second timeout, first all IDs in sorted order,
then a second serial pass. The command templates use `python`; select the recorded
Python 3.12.3 environment explicitly. Create a new result tree and follow the
[current methodology](../../METHODOLOGY.md); never overwrite this bundle.

Times include interpreter startup, imports, conversion, writes and process
cleanup, excluding input hashing and artifact inventory. No peak-memory,
isolated cold-start, warm-conversion or profiler measurement was made. The two
values do not establish a speedup. Compare output bytes and receipt fields,
then repeat source review; deterministic loss is still loss.

This records local baseline evidence. It does not establish CI, release,
installed-wheel acceptance or architecture changes. Publication of the bundle
is separate from those gates.
